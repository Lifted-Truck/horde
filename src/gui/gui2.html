Output & perception

Routes

Right-click any knob or slider and choose “Send to mod matrix”; the route arrives on ENV 1 and the select re-aims it at any source. Depth is ±1 of the destination's full range; the destination's own bounds always clamp the result. Right-click a routed parameter again to release it. The Env > Pitch knob on OSC owns the Pitch row — its depth is in semitones, its source is fixed, and edits in either place stay in step.

Sources

ENV 1 — the amp envelope (loudest voice). ENV 2 — the pitch envelope's own ADSR (the P.Env knobs on OSC). LFOs land here when B16 builds them; the bottom bar is B40.

XY assignment

Which macro each XY pad axis drives, per oscillator. The pads' own selects are the same four values seen through the active oscillator.

Diagnostics — lag bisect

Each switch kills one periodic subsystem LIVE — no reinstall, no reload. Turn them off one at a time and watch the corner's raf number; the line names whatever is off. These are session-local and never saved.

Visualizers

Shows CHROME-002 on MAIN in place of the phase circle. The specimen was exonerated by the excision experiment (the lag was the param-sync repaint, ADR-147) and is fully live again — create-on-show, so OFF means no GL context exists at all.

Keyboard

Off keeps focus in this window, which is what makes computer-keyboard notes linger in Live. On hands focus back to the host after every click.

Patch transfer

COPY puts the whole patch on the clipboard as JSON — the quickest way to send a problem patch. PASTE reads a prompt rather than the clipboard, because clipboard-read permission is unreliable inside plugin webviews while a paste box behaves the same everywhere.

Performance

Performance

Voice Cull sets how quiet a released note gets before the engine stops rendering it. Raising it frees CPU in proportion to how many tails you stack up — most under fast playing with short releases — but it is audible: at −40 dB a tail is still present in a quiet mix. −80 dB is the shipped behaviour.

Panic

Also permanently in the tab bar: it is the control you reach for when something is already wrong, and a stuck note should not outlive a page change.

Morph field

Drag to morph. Each parameter follows the corner that wins its flip — temperature loosens the borders, coupling makes parameters move in blocs, the seed is the patchwork's identity.

Corners

SAVE stores the CURRENT sound as a corner preset — no capture needed. Load it into any corner below; the dropdown keeps the loaded name.
CAPTURE stores the current patch into a corner. Each corner's colour is the swatch beside its name above, and it is what marks that corner's parameters everywhere else in the interface. (Corner baseline-editing — the four color boxes on every page — is the recorded next phase, not this one.)

Morph engine

About the rack

Four slots in series, slot 1 first. Order IS the slot index, so "reordering" means reassigning types. An Off slot is a bit-exact passthrough — it does not touch the buffer at all.
data-fixed on every control here, and that is load-bearing. The rack is ONE object shared by the whole patch, not one per oscillator, and the shell dispatches these by RAW id (id >= 57 && id <= 64), not by base id. Without the pin, selecting oscillator 2 would remap 57 to 1057, match nothing, and silently do nothing — which is exactly what gui.html did until 2026-08-12.
Comp and Comb are real cores (ADR-071), not placeholders; Drive / Filter / Gain are the increment-1 placeholders kept because order is audible with them.
