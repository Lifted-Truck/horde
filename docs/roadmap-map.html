Design ruling · FX

Bounded pool, not once-per-module and not unlimited instances

Every module is a permanent node in the crosspoint matrix; coefficient 0 = absent. Three constraints lock it: ADR-088 made connect/disconnect a continuous coefficient so a morph never hard-cuts topology; QM-4 makes module presence structural (atomic, never blended — an unlimited-instance design would cut reverb tails mid-morph); and real-time safety preallocates. Per-type caps give Serum-like richness (delay ×2, distortion ×2) while singletons stay singletons — the Comb is cap 1 by evidence, and that cap now ships enforced. Open for you: pool sizes, and slots-vs-palette in the UI.
